# PC–phone communication

ROS2 Android uses native ROS 2 Jazzy and Cyclone DDS to exchange topics with Linux
over Wi-Fi or USB networking. No PC relay is required.

Use the current guides:

- [Getting started](GETTING-STARTED.md): install and publish battery percentage.
- [Dashboard](CONTROLS.md): publishers, subscribers and camera viewing.
- [Projects](PROJECTS.md): run deployed code on the phone.
- [Standalone operation](STANDALONE-OPERATION.md): start without a PC and recover
  from connection changes.
- [Compatibility and validation](STATUS.md): supported paths and remaining limits.

For phone-to-microcontroller communication, see [USB micro-ROS](ESP32-USB.md) or
[Wi-Fi micro-ROS](ESP32-WIFI.md).
