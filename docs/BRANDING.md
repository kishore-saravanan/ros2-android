# App icon artwork

Current icon is an original geometric robot in an eight-dot navy grid. The teal
robot has a rounded rectangular head, dark visor, square eyes, side ports and a
single central diamond antenna. It replaces the earlier green Android robot
head; no Android robot artwork or official ROS logo paths remain in the assets.

The design is drawn directly as native Android vector paths. Navy #22314E follows
the app palette; the robot accent is teal #1EA7B8. Resources in android/branding/res
are shared by main app and all runner variants. ic_launcher_ros2 is adaptive with
a white background and mask-safe foreground. Home/About show ic_ros_logo; the
notification uses a monochrome version. Installed-icon tests check the teal mark.

The former Android artwork credit disclosure was removed with that artwork.
Author credit and the GitHub Sponsors link stay visible in the About footer.
Historical verification records describe earlier icon versions; this file records
the current shipped design. This is the project's own visual identity and does
not claim endorsement by Google or Open Robotics.
